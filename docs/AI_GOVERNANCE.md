# AI governance

The platform maps engineering evidence to NIST AI RMF functions.

| Function | Evidence |
|---|---|
| Govern | Ownership, risk register, human approval and change history |
| Map | Intended use, tenant and data classifications, provider inventory |
| Measure | Retrieval, grounding, abstention, injection and latency tests |
| Manage | Quality gate, GitOps rollback, incident runbook and audit trail |

No production promotion occurs solely because a model generated a plausible response. A named human owner accepts model, data, security and operational risk.
