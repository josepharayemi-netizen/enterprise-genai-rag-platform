# System card

## Intended use

Answer internal-policy questions from approved evidence with citations. Local mode is a deterministic demonstrator, not a general-purpose language model.

## Limitations

Lexical hashing does not capture all semantic relationships. Injection detection is defence-in-depth, not a complete solution. Synthetic evaluation cannot establish production safety or fairness.

## Required production controls

Representative evaluation, identity-aware authorization, tenant-isolated indexes, privacy assessment, rate limits, content moderation, human escalation and continuous monitoring.
